    REDUX:
    ------
    1. Redux is a state management library used to manage and centralize application state, especially in large React applications.
    2. Core concepts :
        1. Store: A single source that holds the entire app states.
        2. Action: An object that describes what happens to a state.
        3. Reducer : A function that decides how state changes.
        4. Dispatch : used to send actions to the Reducer
    3. Work Flow :  User Action => dispatch => Reducer => Store updated state => UI rerender
    4. Packages installed :
        - React-Redux : npm install react-redux
            - Provider :  Makes the REDUX store available to all Components in your app.
            - useSelector Hook : used to select reducer from store to component.
            - useDispatch Hook : used to dispatch action from component, it returns a function, it can be used to dispatch action
        - Redux Toolkit : npm install @reduxjs/toolkit
            - configureStore() : used to create store
            - createReducer() : used to create reducer, updated state will be stored in reducer
            - createAction(): used to generate action, logic to update state value
            - createSlice(): used to combine action and its reducer together.
    5.  To Implement Redux Logic in an existing app
        1. Install Packages: npm install @reduxjs/toolkit react-redux
        2.  Create a redux folder  in src
            - Create store.js file to  hold states.
            - Provide the store to Application.
            -  Create slice  to handle the states and actions together.

    DATABASE
--------------------
1. A database is an organized collection of data stored electronically , so that it can easily access , manage and update...
2. Types of Database:
    - Relational Database(SQL based)
    - NoSQL database
3. SQL: Structured Query Language - used to interact with relational DATABASE
    - Here data is stored in Tables
    - Rows(Records) : one entry in table indicate one item stored in table.
    - Column (Field): Attribute of data stored in table.
    - Primary Key : Unique field of a table
    - Foreign Key : used to refer in another table, it always primary key of a table.

    MONGODB
-----------------------
    1. MongoDB is NoSQL database, document -Oriented DB,  that stores data in JSON like format (BSON) instead of tables.
    2. Features:
        - Schema-less( flexible Structure)
        - Scalable
        - Designed for Modern applications
    3. key Features:
        - Database : A container for collection.
        - Collection : Equalent to table in SQL
        - Document : A single record (JSON like object)
        - BSON : Binary version of JSON used internally
        - _id Field : Every document has a unique key- value
    4. Commands general : Commands will identified only by the MongoDB Shell(MONGOSH)
        - show dbs - display the databases in the connection
        - use databaseName - switch the control to the database we want.
    5. CRUD operations in MongoDB
        - Read : To get documents from the collection.
            - find() : used to get all documents in a database collection
                db.collectionName.find(), If we have query find(condition) - condition always written as object 
                    eg: find({name:"Max"})
            - findOne({condition}) : used to get single document
        - Create : To insert document into the collection.
            - insertOne({document}) : used to insert one document into a collection, document can be an object.
            - insertMany([{docu1},{doc2},.....]): used to insert multiple documents at a time into a collection.
        - Update : To edit a document from a collection
            - updateOne({field:{update-query:value}}) : used to update a single document
            - updateMany() :used to update multiple documents at the sametime.
        - Deletion : To remove document from a collection
            - deleteOne(): used to remove single document
            - deleteMany(): used to remove multiple document.
    6. Query Operations :
        - Comparisons : syntax: {field:{comparison-Query:value}} - eg: $eq,$ne,$gt,$gte,$lt,$lte,$in...
        - Logical : syntax- {logicalquery:[{field:value1},{field2:value2}]} - eg: $and, $or,$nor, $not...
        - Evaluation : syntax- {field:{Evaluation-query:value}} - eg: $regex,$text,$exp,$mod,$where.....
    7. Additional Operations : count(),sort() eg: field:1 - ascending order, field:-1-decending order ,limit().....
    8. Update Operators :
        - Field: $inc, $set, $unset , $rename , $currentDate....
        - Array : $pop, $push, $pull, $addToSet
    9. Indexing :  used to make data searching faster in MongoDB.
        - Better performance for large data.
        - Syntax: db.collectionName.createIndex({fieldName:1})
    10. Schema Design : stucture of collection.
        - Embedded schema design: add entire document details
        - Referenced Schema design : using Primary and foreign key references.
    11. Aggregation : used to process and transform data inside db,  It is used for reports, analytics, filtering, grouping, sorting....
        - Syntax: db.collection.aggregate([{stage1}, {stage2}....])
        - MongoDb uses pipeline stages . $group, $sort, $project, $limit, $skip, $lookup.....
            - $lookup : to join collection 
                 - Syntax: db.collectionName.aggregate([
                                {
                                    $lookup: {
                                      from: "Another collectionName",
                                      localField: "field that in out collection",
                                      foreignField: "field from the another collection related to our collection.",
                                      as: "new field to create"
                                    }
                                }
                            ])
     NODE JS
-----------------------
1. Node JS Core  = Runtime  + EventLoop + Async + Modules + Server + APIs
2. Features 
    - Fast Performance : It is using V8 Engine
    - Asyncronous & non blocking  : File reading, API requests, Database queries.
    - Single Threaded with Event Loop : Asyncronous functions handled smoothly, At a time only one operation withh process
    - Scalable
    - Huge Package EcoSystem
    - Cross Platform
    - Real-Time communication : often used in Socket.IO 
    - Opensource
    - JSON FRiently
3. Core concepts in Node JS
    - Runtime Environment : Nodejs allows JS to run outside the browser.
    - Event Loop : NodeJS uses Event loop to handle multiple requests efficiently.
    - Non- Blocking I/O : NodeJS does not wait for one task to finish  before starting another
    - Modules : Node Js code is organized using Modules.
        - Build-in modules : http,fs,path,os
        - CommonJS (Require/module.exports) : used to import/Export files.
        - HTTP servers : create server using HTTP
        - Asyncronous programming : CallBack, promise, async/await.
        - FileSystem : Read/Write files using fs
        - Streams : Using to handle large files efficiently.
        - Buffers :Temporary memory storage for binary data. used in file upload, streams, network data
        - NPM (Node Package Manager): npm is used to install packages.
        - Global : NodeJS global object containing built-in variables/ funtions. It can  used in node app without import/export, eg: consode, setTimeOut, process....
        - Process : Nodejs Global object which provides information and control over the current running NodeJS Application.
            - Environmental variable : Are secret data or configuration of an application, to hold env variables we have to create .env files, it can be accessed via process.env in node app.
